# Aula 03

## Meu Nome

### Visão Geral
Descrição: Perguntar o nome e exibir na tela

---

## Objetivos

1. Perguntar o nome do usuário 
   
    ### Input
    
    ```Portugol
    Escreva("Qual o seu nome?")
    ```

---

2. Ler o nome do usuário 
    
    ### Save Input

    ```Portugol
    Escreva("Qual o seu nome?")
    Leia(nome)
    ```

---

3. Devolver o nome do usuário com saudação  
    
    ### Output

    ```Portugol
    Escreva("Muito prazer, ", nome)
    ```
